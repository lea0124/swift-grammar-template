## 何ができるアプリか（3行）

iPhone で遊ぶ猫ミームの落ち物パズル。指でドラッグして位置を決め、はなすと猫が落ちて、同じ猫どうしがくっつくと進化する。
進化のゴールは10段階目の「伝説の最強猫」。できるだけ早く作ってクリアタイムをきそう、タイムアタック型のゲーム。
ゲームオーバーになっても広告を見れば1回だけ復活でき、見つけると点灯するかくし要素（実績）が7つある。

## 画面
（画面のようすは、海报フォルダにあるポスターと説明書の画像にのっている。）

画面の流れ：
  ホーム画面
    ↓「ゲームスタート」
  プレイ画面
    ↓ クリア ／ ゲームオーバー
  結果画面
    →「もう一度遊ぶ」でプレイ画面へ ／「ホームに戻る」でホーム画面へ

1. ホーム画面：名前を入れて「ゲームスタート」。特別な名前を入れると「原初者の祝福」というかくし画面が出る。
2. プレイ画面：ゲームの途中で「リスタート」や「終了」を押すと、「リスタートしますか？」「ゲームを終了しますか？」の確認が出る。
3. 結果画面（ゲームオーバー）：「広告を見て復活」を押すと11秒の広告画面になり、カウントが0になると「復活する！」が押せる。復活すると箱は空っぽになり、お金とタイムはそのまま続く。

   
## 使った文法・技術

1. Bool（isShowingGame）と if 〜 else で、ホーム画面とゲーム画面を切りかえる
2. func で処理を分ける：tapStartGame（スタートを押したとき）・startGame・restart・returnToHome
3. enum PendingAction と switch で、リスタートと終了の確認を1つにまとめる
4. オプショナル：pendingAction が nil かどうかで、確認を出すかどうかを決める
5. guard 文：ゲームオーバー中・一時停止中などは、操作を受けつけない
6. DragGesture：onChanged で猫を左右に動かし、onEnded で落とす
7. Set：同じ音声ファイルを2回読みこまないように、重複を消す
8. Date と TimeInterval：プレイのタイムと、広告の残り秒数
9. DispatchQueue.main.asyncAfter：少し時間をおいてから処理する（名前を入れて1秒止まったら祝福を出す、など）
10. .preferredColorScheme(.light)：ダークモードでも明るい表示にする
11. @AppStorage：実績の点灯と回数を、アプリを閉じても残す

## 生成AIの使い方（どの場面で、どう使ったか）

・ゲームの最初の形は生成AIに書いてもらい、そこから1つずつ機能を足してもらった。足すたびに Game1、Game2 … Game16 と別のフォルダに保存して、こわれても前の版に戻れるようにした。うまくいかなかった Game5 には ❌ をつけて残してある。（最初は222行、展示する Game16 は4013行）
・テストでは、「どう操作したら、何が起きたか」をAIに説明して、原因を聞いて直してもらった。
    例1：iOS 16 の iPhone で、ゲームオーバー画面のボタンが1つも押せなかった。
    例2：速くタップすると、ルーレットの犬の効果が出る前に、次の猫が落ちてしまった。
・機能がふえるたびに、リスタートしたあと前のゲームのもの（ボール・お金・タイムなど）が残っていないかを、AIに質問しながら restart() の中身で確認した。

## 展示で工夫した点

・展示ではたくさんの人が交代で遊ぶので、結果画面から「もう一度遊ぶ」「ホームに戻る」ですぐ次の人に替われるようにした。
・ゲームの途中でリスタートや終了をまちがえて押しても、確認が出るのでプレイが消えない。終わったあとや、まだ1個も落としていないときは、確認なしですぐ切りかわる。
・ゲームオーバーになってもすぐには終わらないように、広告を見て1回だけ復活できるようにした。
・スタートのときに効果音を先に全部読みこんでおくので、1個目の猫を落としたときに音がおくれない。
・iPhone がダークモードでも明るい画面で表示されるようにした。また、iOS 16 の iPhone でもゲームオーバー画面のボタンが押せるように直した。
・特別な名前で始めると「原初者の祝福」（5000円スタート・アイテム1回無料など）がもらえるかくし要素を入れて、何回も遊びたくなるようにした。
